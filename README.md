<details>
<summary><b>🛰️ SentinelAI — Grounded Disaster Response Intelligence</b></summary>
<br/>

Hybrid RAG system for disaster-response knowledge retrieval, combining sparse and dense retrieval with cross-encoder reranking and grounded, citation-backed generation.

| Aspect | Details |
|---|---|
| **Stack** | FastAPI, React/Vite, FAISS, BM25, Llama 3.70B (Groq), BGE Cross-Encoder |
| **Scale** | Hybrid retrieval pipeline with weighted RRF fusion |
| **Performance** | Achieved 98.8% evaluation score |
| **Security** | Section-level citation verification for grounded outputs |
| **Impact** | Live retrieval, evidence, citation, confidence & pipeline telemetry |
| **Repository** | [ronni86bit/sentinel-ai](https://github.com/ronni86bit/sentinel-ai) |

Built a hybrid RAG system combining FAISS, BM25, weighted Reciprocal Rank Fusion, and BGE cross-encoder reranking for disaster-response knowledge retrieval. Integrated Llama 3.70B via Groq with response verification and section-level citations to generate grounded, source-backed answers. Developed a FastAPI + React/Vite application exposing live retrieval, evidence, citation, confidence scoring, and full pipeline telemetry.

</details>

| Aspect | Details |
|---|---|
| **Stack** | CrewAI, Qdrant, FastAPI, Docker, live web-search tools |
| **Scale** | Multi-agent orchestration with self-correction loop |
| **Performance** | Custom evaluation harness for task completion & citation accuracy |
| **Security** | Containerized deployment via Docker |
| **Impact** | Grounds agent responses in both static knowledge and real-time data |
| **Repository** | Currently in development |

Built a multi-agent research assistant using CrewAI, with planner, retriever, writer, and critic agents collaborating through a self-correction loop to reduce hallucinations in generated reports. Integrated Qdrant vector search with live web-search tool calls. Containerized the system with Docker and exposed a FastAPI backend, with an evaluation harness measuring task completion rate and citation accuracy.

</details>

<details>

<br/>

Multimodal AI assistant combining image classification with retrieval-augmented generation for grounded, source-backed dermatological explanations.

| Aspect | Details |
|---|---|
| **Stack** | EfficientNetB0, FAISS, Sentence Transformers, Llama 3, Streamlit |
| **Scale** | Three-input Siamese EfficientNetB0 model on the Google SCIN dataset |
| **Performance** | CPU-only inference with confidence visualization |
| **Security** | Curated dermatology knowledge base for grounded responses |
| **Impact** | Automated vector index creation & interactive user interface |
| **Repository** | [ronni86bit/dermarag](https://github.com/ronni86bit/dermarag) |

Built a multimodal AI assistant combining EfficientNetB0, FAISS vector search, and Llama 3 to provide grounded explanations for skin conditions. Designed an end-to-end RAG pipeline using Sentence Transformers, FAISS, and a curated dermatology knowledge base to generate source-backed responses with citations. Developed a three-input Siamese EfficientNetB0 model for skin condition classification and integrated it with an LLM-powered explanation pipeline. Deployed the application using Streamlit, supporting CPU-only inference, confidence visualization, automated vector index creation, and an interactive UI.

</details>
